# 7VN Essentials SEO implementation and launch checklist

## Implemented
- Search-oriented homepage title and description
- Canonical URL for the current Pages domain
- Open Graph and Twitter text metadata
- Organization, WebSite and WebPage JSON-LD
- robots.txt and sitemap.xml
- Business supply keyword relevance in visible homepage content

## Important launch tasks
- Confirm the live Cloudflare Pages deployment serves updated HTML, robots.txt and sitemap.xml.
- Verify the canonical URL matches the eventual permanent domain. When a custom domain is connected, update canonical, Open Graph URL, JSON-LD IDs, and sitemap together; redirect Pages hostname if appropriate.
- Verify ownership in Google Search Console and Bing Webmaster Tools and submit sitemap.xml.
- Run Google's Rich Results Test and Schema Markup Validator. Structured data is intentionally limited: no unverified Product offers, availability, review ratings or shipping claims.
- Use real product photos, meaningful alt text, confirmed specs and actual supplier pricing before publishing individual product landing pages and Product structured data.
- Consider dedicated indexable category pages and useful B2B guides once content and products are verified.
- Check Core Web Vitals and image loading on mobile. The current page loads external font and Unsplash resources; optimize and host approved images locally.
- Confirm site indexing is allowed, HTTP status is 200 and no unexpected Cloudflare access restriction blocks crawlers.
- Add a real social preview image before enabling og:image. Avoid generic placeholder images.
- Do not publish false stock, delivery windows, case specifications, discounts or customer reviews.
